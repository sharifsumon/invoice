# CodeCanyon listing — InvoiceHub

Goal: appear as high as possible when buyers search **"invoice"**, **"billing"**, **"invoice software"**, **"billing system"**,
**"invoice management"** or **"CRM invoice"** on CodeCanyon.

## How CodeCanyon search ranks items (what we can and can't control)

Envato does not publish its "Best match" formula. What authors consistently report, and what Envato's own SEO advice says:

| Factor | Weight | What we do |
|---|---|---|
| **Keywords in the item title** | Very high | Put "Invoice", "Billing", "CRM" and "Purchase Order" in the title (below) |
| Tags | High | 15 tags covering every search phrase (below) |
| Description text | Medium | Keyword-rich headings and feature list (below) |
| **Sales, ratings, reviews** | High — and it grows over time | Launch price, fast support, ask happy buyers for a rating |
| Recent updates | Medium | Ship a small update every 4–8 weeks (changelog in the description) |
| Category | Filter | Pick the category buyers browse for invoicing tools (see below) |

**Honest expectation:** a new item with zero sales will not be #1 for "invoice" on day one — that list is led by items with
hundreds of sales. Strong title + tags get us *into* the results and to the top of narrower searches ("invoice crm",
"purchase order invoice", "AI invoice") quickly; sales, ratings and updates move it up for the broad terms.

### Conclusions from the research
1. **Title words + exact tags decide whether we appear at all**; sales and reviews decide the order. #3 ranks with 6 tags
   and a one-paragraph description because "Invoices" is in its title.

## Submission checklist (Envato review)

Envato reviews every item before it goes live. Still to prepare:

- [ ] **Documentation** (required) — HTML/PDF guide: requirements, installation (Node, PostgreSQL, `.env`, migrations,
      first admin), configuration (company, currency, SMTP, AI key), updating, FAQ. Envato rejects items without it.
- [ ] **Clean download package** — source without `.env`, `node_modules`, `.next*`, `storage/`, test databases or
      personal data; an `.env.example`; a fresh seed with demo data only.
- [ ] **Easy installation** — buyers expect a guided first run (create admin, company, currency) instead of editing
      files; consider a one-command Docker Compose setup as well.
- [ ] **Live demo** at invoicehub.online with a demo login shown on the sign-in page, data reset nightly,
      destructive actions disabled for the demo account.
- [ ] **Preview images** — 80×80 thumbnail and the inline preview banner (check the exact size on the upload form),
      plus 6–10 screenshots: homepage, dashboard, PO with milestones, invoice + PDF, payments, AI assistant chat, reports.
- [ ] **Licensing** — the subscription/plans feature means buyers can run it as a SaaS; Envato requires the
      *Extended License* for that. State it clearly in the description.
- [ ] **Support policy** and an update plan (changelog in the description).
